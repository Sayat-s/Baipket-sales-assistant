# Ликвидация: ОП ботқа жаңартулар

Жаңа өнім (Senior Marketer ликвидация) үшін `baipket-op-bot` (`@sayatassistantbot`) жаңартуы. Кесте тек оқылады.

## Не істейді

- **Табло** (`/tablo`, сондай-ақ `/dashboard`, `/report`): студенттер базасынан оплата санайды, PNG сурет жасайды. Жоспар 261 оплата, 17–30.11. Сақина, баға баспалдағы (179 → 239 → 299 мың), менеджерлер жарысы.
- **Азартты пуштар**: күніне 3 сурет (13:00 бастау, 17:00 күн ортасы, 20:00 қорытынды). Әр жаңа оплатаға бөлек жылдам хабар («🔥 Арман · +1 оплата!»). 50/100/150/200 және 25/50/75/100% белестерінде сурет.
- **Геолокация түзетуі**: келу уақыты хабарлама жіберілген уақыт бойынша жазылады (бот кеш өңдесе де штраф қате шықпайды); forward елеңмейді; демалыс күні жазылмайды; офис нүктесін жеке чатта геолокация жіберіп қоюға болады (`/setoffice` да бар, енді config.json-ға жазбай, дерекқорға сақтайды).
- **КЭВ/созвон функциялары өшіріледі** (`recognition`, `kev`, `reports`, `wins`, `dashboard`, `calendar_hourly`, «норма 4 созвон» таңғы брифингі). Келу белгісі мен штраф қалады.
- **Дашборд жазулары көрінбеуі** (қаріп жоқ) түзетіледі: Dockerfile-ға `fonts-dejavu-core`, `fonts-liberation`.
- **Grok/OpenAI-үйлесімді API**: `OPENAI_BASE_URL` берілсе, барлық AI шақырулар сол мекенжайға барады (жоқ болса, OpenAI).

- **Табло мотивациясы**: лидер баннері («2-орыннан +N»), «Жоспарға тағы N оплата керек», Ожидается / Факт / Остаток, әр менеджердің лидерге дейінгі айырмасы. Жеңімпаз сыйлығы бар болса, `liquidation.prize` мәтінін қойыңыз.
- **ЗП есебі** (`/zp`, тек Саятқа жеке чатта, күн сайын 21:00-де өзі де келеді): толық оплата × 10 000 + предоплата × 5 000 − штраф. Ставкалар `bonus` баптауынан алынады, басқа формула болса `liquidation.salary` (`full`, `pre`, `percent`).
- **Анкета -> кесте**: Саят ботқа (жеке чатқа) студент анкетасын жібереді (мәтін немесе forward). Бот өрістерді тауып, алдын ала көрсетеді, «✅ Қосу» басқанда сәйкес қала парағының бірінші бос жолына жазады. Жетіспесе (МОП, Внесла) соны жазасыз: `МОП: Арман` / `Внесла: 179000`. Қайталанған телефон ескертіледі, формула мен толтырылған ұяшыққа тиілмейді.

## Серверде орнату

```bash
cd /opt/op-bot
curl -fsSL https://raw.githubusercontent.com/Sayat-s/Baipket-sales-assistant/claude/adoring-noether-eiml2n/bots/op-liquidation/apply_liquidation.py -o apply_liquidation.py
python3 apply_liquidation.py --sheet-id <ЛИКВИДАЦИЯ БАЗА СТУДЕНТОВ кестесінің ID-і>
docker compose build && docker compose up -d
```

Орнатушы алдымен `/opt/op-bot-backup-<уақыт>` жасайды, қайталап іске қосуға болады. Күтілген код нұсқасы болмаса, ештеңе өзгертпей тоқтайды.

## Қажет

- Кестеге service account email-ін **Editor** ретінде қосу (анкета жазуы үшін; тек табло керек болса Viewer жеткілікті) (email: `python3 -c "import json;print(json.load(open('secrets/google-service-account.json'))['client_email'])"`).
- Кестедегі парақ аттары `Алматы`, `Астана`, `Шымкент`, `Ақтау`; бағандар: МОП, ФИО, Телефон, Дата покупки, Договоренная сумма, Внесла, Остаток.
- Санау: `liquidation.count_mode` = `paid` (ақша түскен әр студент, алдын ала төлем де) немесе `full` (толық төленгені ғана).
